# MOSAIC — the Modular, Open-Source Suite for Assistive Intelligent Control

*An extensible platform for biosignal processing, human-machine interfaces, and assistive robotics.*


### What is MOSAIC?

MOSAIC is an open-source software platform that makes it easy to design, prototype, and deploy advanced control systems for assistive devices.  
With MOSAIC, you can rapidly connect sensors, filters, feature extractors, machine learning blocks, and device controllers—no need to reinvent the wheel.

**Key Features:**
- **Modular block-based architecture** for flexible pipeline design
- **Real-time processing** for sEMG, IMU, force, ultrasound, and more
- **Plug-and-play device integration** (e.g., Delsys, Myo, Blender models)
- **Built-in visualization and monitoring tools**
- **Standardized assessment protocols** (e.g., Target Achievement Control)
- **Open source & extensible** (C#/.NET Framework 4.8)

### Who is it for?

- Students and researchers in **prosthetics**, **rehabilitation engineering**, **biosignal processing**
- Anyone interested in **human-machine interfaces** and **assistive robotics**
- Those who want a fast, transparent starting point for their own experiments
